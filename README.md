# GLaDOS - Discord bot to make server more group-like.
Code is configured for my specific server and raspi at the moment.
Runs on raspberry pi, loadscript used for running the bot on startup.
pc_connector.py meant to be executed from pc to poll for pause requests

# Features:
    - Message Logging
    - Ringing for calls
    - Member specific ringing
    - Ring all members
    - Call durations 
    - Guest Access Handling
    - Debug commands
    - Remote control bot (chat)
    - AI Chatbot
    - Scramble! (mix up everyones names and colors)
